Input 输入框 ​

跨端输入组件，支持多种类型、清除按钮、前后缀图标与 textarea。

基础用法 ​

vue
<ju-input v-model="value" placeholder="请输入" />
<ju-input v-model="pwd" type="password" placeholder="请输入密码" />
<ju-input v-model="remark" type="textarea" :rows="4" placeholder="留言" />

图标与对齐 ​

vue
<ju-input v-model="phone" prefix-icon="phone" type="number" placeholder="手机号" />
<ju-input v-model="code" suffix-icon="check" placeholder="验证码" input-align="right" />
