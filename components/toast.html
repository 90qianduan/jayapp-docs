Toast 轻提示 ​

轻量反馈，不打断操作。页面放置一次 <ju-toast /> 单例后，可通过 $jay.toast 函数式调用。

基础用法 ​

vue
<template>
  <ju-toast />
  <ju-button text="提示" @click="onTip" />
</template>

<script setup>
import { getCurrentInstance } from 'vue'
const { proxy } = getCurrentInstance()

function onTip() {
  proxy.$jay.toast('操作成功')
  proxy.$jay.toast({ message: '带图标', type: 'success' })
  proxy.$jay.toast({ message: '加载中', type: 'loading', duration: 0 })
}
</script>

函数式 API ​

$jay.toast(options) 的参数支持字符串或对象：

参数说明类型默认值
message / title提示文案（二选一）String-
type类型：success | error | warning | loadingString-
icon自定义内置图标名，优先于 typeString-
duration展示时长 ms，0 为不自动关闭Number组件默认
position位置：center | top | bottomString组件默认

组件 Props ​

参数说明类型默认值
duration默认展示时长 ms，0 为不自动关闭Number2000
position默认位置：center | top | bottomStringcenter
customStyle自定义样式Object | String-
customClass自定义类名String-

组件 Methods（ref 调用） ​

方法名说明
show(options)显示
success(title, options)成功提示
error(title, options)失败提示
loading(title, options)加载中（不自动关闭）
hide()立即隐藏

TIP

type: 'loading' 会展示转圈动画并默认不自动关闭，请求完成后调用 $jay.toast({ message: '完成', type: 'success' }) 覆盖即可。
