Form 表单 ​

由 ju-form + ju-form-item + 数据组件组成，内置声明式校验引擎。

基础用法 ​

vue
<template>
  <ju-form ref="formRef" :model="model" :rules="rules">
    <ju-form-item label="用户名" prop="name">
      <ju-input v-model="model.name" placeholder="请输入用户名" />
    </ju-form-item>
    <ju-form-item label="手机号" prop="phone">
      <ju-input v-model="model.phone" type="number" placeholder="请输入手机号" />
    </ju-form-item>
  </ju-form>
  <ju-button block text="提交" @click="onSubmit" />
</template>

<script setup>
import { reactive, ref } from 'vue'
const formRef = ref(null)
const model = reactive({ name: '', phone: '' })

const rules = {
  name: [
    { required: true, message: '请输入用户名' },
    { pattern: /^.{2,12}$/, message: '用户名需 2-12 个字符' }
  ],
  phone: ['mobile'] // 内置规则名简写
}

async function onSubmit() {
  try {
    await formRef.value.validate()
    // 提交逻辑
  } catch (errors) {
    // errors: [{ prop, message }]
  }
}
</script>

校验规则 ​

每个字段对应一个规则数组，规则项支持：

写法说明
{ required: true, message }必填校验
'mobile' / 'email' / 'url' 等内置规则名简写（见 $jay.test）
{ pattern: /^...$/, message }正则校验
{ validator: (value) => true/false/string, message }自定义校验函数
