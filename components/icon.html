Icon 图标 ​

内置 32 个常用 SVG 图标，跨端渲染为 data-uri image，无需字体依赖。

基础用法 ​

vue
<ju-icon name="check" />
<ju-icon name="search" size="24" color="#2979ff" />

Props ​

参数说明类型默认值
name内置图标名，见下方列表String-
size图标尺寸，数字默认 pxString | Number16
color图标颜色，默认跟随主题文本色String-
customStyle自定义样式Object | String-
customClass自定义类名String-

Events ​

事件名说明回调参数
click点击图标event

内置图标列表 ​

check  check-circle  close  close-circle
arrow-right  arrow-left  arrow-down  arrow-up
search  plus  minus  star  heart
home  user  phone  mail  camera  image
trash  edit  download  upload  share  refresh
warning  info  settings  eye  more  calendar  location

编程式获取图标 ​

js
import { icons } from 'jayapp'

console.log(Object.keys(icons)) // 所有内置图标名
