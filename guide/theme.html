运行时主题 ​

jayapp 的主题系统基于 Design Token + CSS 变量，亮/暗模式在运行时即时切换，无需重新编译。

三层 Token 体系 ​

  1. 语义色：--jay-color-primary / success / warning / error / info 及各自的 -disabled、-light 变体。
  2. 文本 / 背景 / 边框：--jay-text-color*、--jay-bg-color*、--jay-border-color*、圆角、字号、间距。
  3. 组件级：--jay-cell-bg、--jay-toast-bg、--jay-modal-bg、--jay-popup-bg 等。

组件样式统一消费这些变量，因此切换主题时所有组件即时响应。

切换亮 / 暗 ​

js
import { setTheme, toggleTheme } from 'jayapp'

setTheme('dark')   // 切到暗色
setTheme('light')  // 切回亮色
toggleTheme()      // 亮暗互切

或在页面内使用 composable：

vue
<template>
  <page-meta :root-style="themeStyle" />
  <switch :checked="isDark" @change="onChange" />
</template>

<script setup>
import { useTheme } from 'jayapp'
const { isDark, themeStyle, setTheme } = useTheme()

function onChange(e) {
  setTheme(e.detail.value ? 'dark' : 'light')
}
</script>

多端说明

  • H5 / App：setTheme 直接把 CSS 变量写入根节点（documentElement），挂载到 body 的弹层也能消费。
  • 小程序：通过 <page-meta :root-style="themeStyle" /> 把变量注入页面根节点。

自定义品牌换肤 ​

传入 Token 覆盖对象即可，未覆盖的 Token 保持亮色默认：

js
setTheme({
  '--jay-color-primary': '#7c3aed',
  '--jay-color-primary-light': '#f3e8ff'
})

SCSS 变量 ​

在 uni.scss 引入 jayapp/theme.scss 后，业务样式可使用与 CSS 变量一一映射的 SCSS 变量：

scss
.my-card {
  color: $jay-text-color;          // => var(--jay-text-color, #303133)
  border-radius: $jay-radius;      // => var(--jay-radius, 8px)
  background: $jay-cell-bg;        // => var(--jay-cell-bg, #ffffff)
}

注意

不要在 @each 循环里用 $jay-color-#{$type} 这类插值变量名引用主题变量（部分构建管线下作用域不可用）。请改用自包含的 Sass map + CSS 变量，参考 ju-button 的实现。
