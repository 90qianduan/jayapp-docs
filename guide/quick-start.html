快速上手 ​

三四行接入 jayapp，本文以 uni-app Vue3 + Vite 项目为例。

安装 ​

bash
npm install jayapp
bash
pnpm add jayapp

配置（四个文件） ​

1. main.js —— 注册插件 ​

js
import { createSSRApp } from 'vue'
import jayapp from 'jayapp'
import App from './App.vue'

export function createApp() {
  const app = createSSRApp(App)
  app.use(jayapp) // 全局注册组件 + 挂载 $jay
  return { app }
}

2. uni.scss —— 引入主题 SCSS 变量 ​

scss
@import 'jayapp/theme.scss';

引入后，你的业务样式可直接使用 $jay-color-primary、$jay-radius 等 SCSS 变量（自动映射到 CSS 变量并带亮色兜底）。

3. App.vue —— 引入基础样式与 CSS 变量 ​

vue
<style lang="scss">
@import 'jayapp/index.scss';
</style>

index.scss 向根节点注入亮色默认 CSS 变量，并提供 reset 与工具类。

4. pages.json —— 配置 easycom 按需引入 ​

json
{
  "easycom": {
    "custom": {
      "^ju-(.*)": "jayapp/components/ju-$1/ju-$1.vue"
    }
  }
}

配置后即可在任意页面直接使用 <ju-button>、<ju-cell> 等标签，无需手动 import，且按需打包。

使用组件 ​

vue
<template>
  <ju-button type="primary" text="主按钮" @click="onClick" />
</template>

<script setup>
import { getCurrentInstance } from 'vue'
const { proxy } = getCurrentInstance()

function onClick() {
  proxy.$jay.toast({ message: 'Hello jayapp', type: 'success' })
}
</script>

使用函数式 API ​

在页面放置一次 <ju-toast /> / <ju-modal /> 单例，即可在任意位置函数式调用：

vue
<template>
  <ju-toast />
  <ju-modal />
</template>

<script setup>
import { getCurrentInstance } from 'vue'
const { proxy } = getCurrentInstance()

async function del() {
  const res = await proxy.$jay.modal({ title: '确认删除？', content: '删除后不可恢复' })
  if (res === 'confirm') proxy.$jay.toast('已删除')
}
</script>
