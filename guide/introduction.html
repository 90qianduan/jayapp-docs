介绍 ​

jayapp 是一个面向 uni-app Vue3 的跨端 UI 组件库，以运行时主题、完整类型提示与单元测试保障，提供现代、易用的多端组件体验。

产品定位 ​

  • 轻便：零运行时依赖，easycom 按需加载，用多少打包多少。
  • 易用：三四行完成接入；智能默认值；$jay 全局对象提供一行式函数 API。
  • 丰富：首期提供 10 个核心组件范本，路线图覆盖 60+ 组件。
  • 多端：H5、小程序、App 无感适配，样式与行为全端一致。

核心优势 ​

jayapp 在以下维度做了代际升级：

  1. 运行时主题系统：基于 Design Token + CSS 变量，亮/暗模式运行时即时切换，无需重新编译；支持传入自定义 Token 覆盖，轻松实现品牌换肤。
  2. Composition API + 类型提示：组件全部 <script setup> 编写，useProps composable 替代 mixin；JSDoc + .d.ts 提供完整类型提示。
  3. 单元测试体系：内置 Vitest + @vue/test-utils 测试，核心逻辑与组件行为可验证、可回归。

设计原则 ​

  • 组件样式统一消费 CSS 变量（var(--jay-xxx, 兜底值)），保证运行时主题在所有端生效。
  • 函数式 API（$jay.toast / $jay.modal）通过全局事件总线与页面单例组件通信，任意位置一行调用。
  • 源码即 npm 包：目录结构即发布结构，npm publish 直接可用。
