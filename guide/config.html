全局配置 ​

jayapp 支持在安装时或运行时修改全局默认配置，实现「一次配置，全局生效」。

安装时配置 ​

js
import jayapp from 'jayapp'

app.use(jayapp, {
  props: {
    button: { size: 'large' },   // 全局按钮默认大尺寸
    cell: { arrow: true }        // 全局 cell 默认带箭头
  }
})

运行时配置 ​

js
import { setConfig } from 'jayapp'

setConfig({
  props: {
    popup: { round: 16 }
  }
})

配置优先级 ​

组件最终 props 的合并优先级（高 → 低）：

  1. 页面中显式传入的 props
  2. 全局配置 $jay.props[组件名]
  3. 组件内置默认值

原理

useProps composable 通过 vnode 检测用户显式传入的 key，与全局配置深合并，保证「用户传了就以用户为准」。

$jay 全局对象 ​

app.use(jayapp) 后，任意组件内可通过 getCurrentInstance().proxy.$jay 访问：

成员说明
version当前版本号
util工具函数（addUnit / debounce / deepMerge / guid 等）
test校验函数（mobile / email / idCard / url 等）
date日期函数（timeFormat / timeFrom / toDate）
toast(options)函数式轻提示
modal(options)Promise 化确认弹窗
route(url, params)路由跳转简写（navigateTo 失败自动降级 switchTab）
setTheme / toggleTheme运行时主题
setConfig(config)全局配置
